refactor(resource-detail): migrate to dialog-based editing with auto-save

BREAKING CHANGE: Metadata editing now uses a dialog instead of inline toggle mode

## What Changed

### New Dialog-Based UX
- Metadata editing now opens in a dialog (matching Notes/Transcript UX)
- All three editors (Metadata, Notes, Transcript) now have consistent behavior
- Clean separation of concerns following Single Responsibility Principle

### Auto-Save Features
- Silent auto-save with 60s debounce on all editors
- Exponential retry (5 attempts: 500ms, 1s, 2s, 4s, 8s)
- Navigation protection (blocks navigation until auto-save completes)
- Browser unload protection (prevents tab close during active save)
- Inline error notifications after retry exhaustion

### Architecture Improvements
- Refactored ResourceDetail.tsx from 1,114 lines → 320 lines (71% reduction)
- Created 4 new focused components:
  - MetadataEditorDialog (metadata editing dialog)
  - ResourceMetadataCard (metadata display + edit trigger)
  - ResourceNotesCard (notes display + edit trigger)
  - ResourceTranscriptCard (transcript display + edit trigger)
- Lazy loading for dialog components (load on-demand, not upfront)
- Better performance (reduced initial bundle size)

### Bug Fixes
- Fixed useNavigationBlocker to use stable React Router API (useBlocker)
- Removed console warning about unsupported blocking
